H56 executive summary

Use the full published metric for every binary raster: DTI = T / (T + 0.2(N - M) + 0.8(G - T)), where T=TP_w is truth-side credit and M is summed prediction-side matched credit. The often-used simplification T/(0.2N + 0.8G) requires T=M; 3 px dot spacing alone does not establish it. Dense top-N picks can still saturate truth-side credit while increasing prediction-side false-positive cost. The legacy H56 transfer-model output was not recalculated under this clarification and is not a score forecast. The historical H56 raster used the old block-quantised emitter (measured minimum nearest-neighbour distance 1 px); the weighted Euclidean Poisson-disk emitter is now corrected for future builds, but this file was not rebuilt.
