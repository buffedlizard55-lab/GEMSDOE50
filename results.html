Uniqueness

Block-level Jaccard against 50 frozen prior artifacts: worst case 0.6597 against gems16-h16-1-topo-geophys-baseline-ridges-20260930-df20f65e-nan.tif. That number is only meaningful next to its null distribution — among genuinely independent prior artifacts the same statistic has median 0.8252 and maximum 1.0000, and this file sits below that median. The audited statement is narrower: a new sha256, no prior raster read into the belief field, and 2.72% exact-pixel overlap with the only prior submission available locally (evidence/uniqueness_h51.json).
