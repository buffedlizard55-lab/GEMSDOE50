## Score context

An archived GEMSDOE50 report associates `0.2778` with H33-2-B2, but the current [GEMSDOE32 owner site](https://buffedlizard55-lab.github.io/GEMSDOE32/docs/index.html) labels H33-2-B2 unscored and `0.2747` a model projection. Without an organizer receipt or verified score-to-file mapping, the `0.2778` association remains unresolved. The `0.3195` value is owner-provided historical context only; it is not independently verified, not asserted to be the current lead, and not mapped to a verified TIFF. Sibling-repository notes conflict and no fresh official board check was performed. No score-to-TIFF mapping is authenticated without an organizer receipt. DrivenData's Terms of Use restrict automatic and unauthorized manual monitoring/copying; this repository does not poll or copy leaderboard rows.

## Limits

Prior repositories contain owner-authored descriptions and reported local results. They are useful to prevent duplicate work and choose controls, but the current project has not independently reproduced their code, inputs, splits, or numerical results. When a prior raster is used as a comparator, it must be re-read from bytes, hash-pinned, and scored under GEMSDOE50's frozen spatial folds; its published score must not be imported as the comparator metric.
