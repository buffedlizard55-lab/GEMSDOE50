Why this file is different

  • It derives fault lines from the earthquake point pattern, not from a density band. Epigonal clusters are split recursively until the minor-axis σ ≤ 600 m, kept only if linear and well sampled, and emitted as thin axes plus gap connectors — a corridor prior, not a smear.
  • The placement step snaps every corridor onto the lidar scarp ridge (USGS 3DEP 1 m descriptors), so a corridor is only predicted where the topography independently shows a scarp.
  • Leakage-free falsification: with only pre-2020 earthquakes the detector is the only field that touches the 2020 Monte Cristo rupture trend at all; smoothed density and random controls at matched mass touch none of it (table).
  • It does not copy anything: max correlation 0.033 with 119 prior rasters, including every file in this organisation's other repositories.
