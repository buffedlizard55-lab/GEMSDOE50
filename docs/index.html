🔬 Method Summary

H60: Anisotropic Seismicity KDE × Distance-to-Known-Faults Prior

  • Declustered USGS ComCat epicenters (90,897 events after screening)
  • 2-D covariance eigenstructure per event neighborhood → 1,366 linear clusters
  • Oriented Gaussian KDE along fault strike, width from location error
  • Combined multiplicatively with distance-to-known-faults prior (peak at 3km)
  • Blue-noise emission at 3px spacing (metric's own 300m support)
  • 55,000 predicted dots, all outside 300m of known catalogue
