# Distinct geological-hypothesis review

**Version:** 2026-10-06, reviewed before H50-S1's first DTI. This ranks testable hypotheses by expected incremental value, independence from project history, implementation readiness, data rights, and validation cost. It is not a score forecast. No candidate gets a submission slot without the fixed blocked holdout, matched controls, artifact validation, and human review.

## H50-RC concept: minimum pre-registration if it is ever advanced

Use USGS 3DEP elevation and NHDPlus HR stream-network data to derive longitudinal channel profiles. Identify abrupt, spatially persistent changes in normalized channel steepness or profile gradient using parameters fixed on non-holdout watersheds. A candidate line may be emitted only when a preregistered number of independent catchments show a compatible profile break near the same mapped corridor, with no one basin dominating. Do not use the training-label raster to fit profiles or select the threshold.

Controls must match drainage area/stream order, lithology and DEM quality; explicitly exclude or mark dams/reservoirs, major base-level transitions, and obvious anthropogenic channels. Use spatially translated channel-network controls and matched non-fault catchments. Hold out whole geographic blocks with the existing visible-label buffer. 3DEP and NHDPlus HR are official USGS public-domain/open products, but coverage/resolution varies and NHD is a legacy program being superseded by 3DHP. Sources: [USGS 3DEP 1 m DEM collection](https://data.usgs.gov/datacatalog/data/USGS:77ae0551-c61e-4979-aedd-d797abdcde0e), [USGS National Hydrography access](https://www.usgs.gov/national-hydrography/access-national-hydrography-products), [NHDPlus HR metadata](https://data.usgs.gov/datacatalog/data/USGS:0826ab39-e5bd-47e6-ba8f-56f340094f81). The regional plausibility reference, Ellis et al. (2014), documents fault-proximal river-profile knickpoints in northwestern Nevada while noting climate as an alternative: [doi:10.1130/L401.1](https://doi.org/10.1130/L401.1). This supports a testable mechanism, **not** a performance claim.

## Promotion protocol shared by the top candidates

1. Re-check the exact hypothesis against `docs/hypotheses-preregistered.md`, historical code, and available artifacts before implementing anything.
2. Freeze input hashes, prediction rule, geographic folds, visible-fault buffers, smoothing/declustering/site-mask parameters, and controls before DTI computation.
3. Compare against the fixed incumbent, matched smoothed-density map(s), translated spatial controls, and appropriate event-year/sequence nulls. Require positive paired fold deltas, block-bootstrap uncertainty above zero, and the preregistered absolute improvement threshold.
4. Preserve raw source/license receipts and candidate provenance. Never copy prior submission pixels into a candidate. A numerical proxy pass is not an organizer score and cannot override a failed source-rights, uncertainty, confound, or unique-TIFF gate.
