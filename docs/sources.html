Verification status, stated plainly. Every competition-document link, data source and DOI above was opened and read in this session except where noted. Two caveats are flagged rather than hidden: (1) the exact wording of the rules PDF’s external-data clause is quoted from the problem description page and should be re-read at the PDF before a public claim is made about it; (2) the Koehler et al. surface-rupture paper is used only to justify the existence of the unmapped 2020 rupture, which the catalogue itself establishes (20,570 events, Mw 6.5 mainshock, 49 px from the nearest catalogue cell) — the geometry used in the test is derived from the sequence’s own epicentres, not from that paper.
